Unit Testing:
Unit testing checks individual functions, methods or classes independently without launching the complete application interface. It verifies whether the program logic produces the expected output for different inputs.

Example: Testing whether a grade calculator correctly calculates a student's average marks.

UI Testing:
UI testing checks the application's user interface and complete user interactions. It launches the application, taps buttons, enters information into fields and verifies the visible results.

Example: Automatically entering a student's name and marks, submitting the form and checking whether the student details appear on the screen.

Conclusion:

Unit testing focuses on individual pieces of code, whereas UI testing focuses on the complete user journey and interaction between interface elements. Both are important for building reliable applications.
